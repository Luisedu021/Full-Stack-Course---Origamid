# Origamid — Full Stack Studies

Study repository for the **[Origamid](https://www.origamid.com/) Full Stack course**.
Each folder is an exercise or practice project built while going through the course,
starting with the **HTML and CSS** modules.

## Goal

Practice and keep a record of my progress through the web development fundamentals:

- Semantic HTML structure
- CSS: selectors, box model, typography, colors and layout
- File organization and navigation between pages
- Coming next: JavaScript, front-end frameworks and back-end

## Structure

| Folder | Description |
| --- | --- |
| `Carros_e_Bicicleta/` | HTML and CSS exercise with product cards (price, model and a buy button). |
| `cinema/` | Home page linking to state pages (`estados/rj.html`, `estados/sp.html`) with movie showtimes. |
| `pratica/` | Practice page covering headings, links and the use of `id` and `class`, plus `produtos/` subpages. |

Each project follows the same pattern:

```
project/
├── index.html    # page markup
├── style.css     # styles
└── assets/       # images (when present)
```

> Page content is written in Portuguese, matching the course material.

## Running locally

No build step and no dependencies — plain HTML and CSS.

1. Clone the repository:
   ```bash
   git clone <repository-url>
   ```
2. Open the `index.html` of any project in your browser.

For automatic reload on save, one option is the VS Code
[Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer)
extension.
